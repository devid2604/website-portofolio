HZ HBO-ICT - Examenplanning Leerjaar 1
Mijn HZ ICT Examenplanning & Voortgang (Leerjaar 1)
Quartile HBO ICT (Course) description Credits (EC) Cijfer
Q1 Programme- & Career Orientation In this course, you will discover your motivation for IT and set your goals for learning and growing as an IT professional. 5.0 5.8
Q1 Programming Basics In this course, you will learn the basics of programming using JavaScript. You will learn the structure of a software application and the different ways to control the flow. 5.0 6.2
Q1 Computer Science Basics In this course, you will learn the basics of what makes a computer function. This knowledge will be the foundation for all computer-related learning 5.0 5.6
Q2 Object-Oriented Programming In this course, you will continue learning the basics of programming, but using TypeScript as your introduction into Object Oriented Programming. You will use these principles to develop a basic game engine and develop small games. 5.0 6.6
Q2 Agile and Team Management Course In this course, you will learn how an IT project is managed and operates indiviudally as well as within a team. 5.0 5.5
Q2 Project: Foundations In this course, you will complete your first project for a given target audience, primary school children. You will develop an educational game using stakeholholder and what you learnt so far. 5.0 6.3
Q3 Software Engineering Basics In this course, you will learn the foundations of sofware engineering. You will use architecture and design patterns to develop robust, sustainable software. 5.0 6.6
Q3 Foundations of Data In this course, you will be introduced to the data life cycle. You will learn to design relational databases using SQL and apply CRISP-DM principles to assess and clean data using Python, bridging the gap between software development and data science. 5.0 6.9
Q3 quirements Modelling In this course, you will learn to elicitation and requirements modelling techniques to describe what is needed from a software project. 5.0 7.1
Q4 Web Application Development Course i In this course, you will use PHP to develop a web application framework from scratch. You will use your knowledge from software engineering as well as data science to build a industry-standard framework. 5.0 6.8
Q4 Data Science Basics In this course, you will be introduced to the workflow of a Data Scientist using the CRISP-DM framework. Building on your data preparation skills, you will perform exploratory data analysis (EDA)to find patterns and use Python to build and evaluate baseline and basic regression and classification models. 5.0 5.8
Q4 Applied Client Solutions In this course, you will work in a team to build a solution for a given client. You will analyse their problem, design and realise an appropriate solution. You will use an agile project management processes to manage your project. 5.0 4.9
Totale Studiepunten Jaar 1 50.0 EC 6.2
