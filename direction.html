Toekomstige ICT-richting

Voor deze pagina heb ik twee richtingen bekeken: Data Science en Software Engineering.

Hieronder schrijf ik wat ik van beide richtingen heb begrepen, wat je in de praktijk doet en welke richting het beste bij mij past.

Data Science

Wat is Data Science?

Bij Data Science werk je met grote hoeveelheden data (informatie). Je verzamelt die data, maakt het netjes en zoekt er patronen in. Met statistiek en programma's kijk je wat de data vertelt, zodat een bedrijf betere beslissingen kan nemen.

Wat doe je dan de hele dag?

  • Data verzamelen en opruimen (vaak met Python of SQL)
  • Grafieken en tabellen maken zodat anderen het ook snappen
  • Modellen bouwen die iets voorspellen (machine learning)
  • Uitleggen wat je hebt gevonden aan mensen die niet technisch zijn

Waar werk je?

Overal waar veel data is: banken, zorginstellingen, webshops, de overheid en grote techbedrijven.

Wat vind ik ervan?

Ik vind het interessant dat je uit cijfers een statistische verhaal kunt halen, maar het lijk me te chaotisch.

Software Engineering

Wat is Software Engineering?

Bij Software Engineering bouw je software: websites, apps en programma's. Het is meer dan alleen code typen. Je bedenkt eerst hoe iets moet werken, bouwt het daarna en test het tot het echt goed werkt.

Wat doe je dan de hele dag?

  • Code schrijven (bijvoorbeeld Java, Python of JavaScript)
  • Samenwerken in een team en elkaars code lezen
  • Bugs vinden en oplossen
  • Code testen en bewaren met Git

Waar werk je?

Bij softwarebedrijven, bij een bedrijf met een eigen ICT-afdeling, of je begint je eigen bedrijf. Ook kun je freelance werken. Bijna elk bedrijf heeft mensen nodig die software kunnen bouwen.

Wat vind ik ervan?

Dit past het beste bij mij. Ik vind coderen leuk en ik wil iets maken dat mensen echt gebruiken. Ook kan ik mijn oude skills (als retail manager) gebruiken om rekening te houden met hoe de bedrijfswereld werkt. Dat komt ook terug in mijn motivatie op de Why ICT? pagina.

Mijn voorkeur

Mijn keuze is Software Engineering.

Ik wil iets bouwen dat mensen gebruiken, en daar begint het bij zelf code schrijven.

Dit sluit aan bij mijn doel om later een programma voor een bedrijf te maken (zie de Goals pagina).

Waarom niet Data Science?

Data Science past wat minder bij mij het is te chaotisch denk ik. Tijdens de opleiding kom ik het sowieso tegen en wie weet vind ik het later juist leuk om mee te combineren.

Hoe dit past bij mijn SWOT: mijn weakness "plannen" wordt makkelijker als ik in kleine stapjes werk met deadlines, zoals je dat bij software projecten doet. Mijn strength "leergierig" helpt mij om nieuwe dingen te leren. En omdat ik gevoelig ben voor tijdsdruk (threat) is het goed dat ik bij een team werk waar ik taken kan verdelen.
